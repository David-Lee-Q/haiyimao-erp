## 一、系统概述

海易贸 · 生鲜外贸ERP 面向进口生鲜外贸场景，覆盖**境外采购 → 国际货运单证 → 保税冷链仓储 → 落地成本核算 → 销售出库**的完整业务闭环。

核心能力：

| 能力域 | 说明 |
|---|---|
| 采购订单管理 | 多币种锁汇、双单位联动、采购审批状态机 |
| 国际货运与单证 | 货运批次节点流转、单证核销矩阵 |
| 保税冷链仓储 | 重公差校验、批次追溯、FEFO 先到期先出 |
| 落地成本核算 | 按重量/货值/件数分摊、关税增值税倒算 |
| 冷链温控监控 | IoT 温度告警、异常批次自动锁定 |

登录方式：使用企业账号登录；系统按角色动态展示菜单与操作按钮，无权限的功能不会出现。

## 二、角色与权限总览

系统共 6 个角色，权限通过代码内静态权限矩阵控制（后端 `backend/src/permissions.js`）。

| 角色 | 账号 | 定位 | 权限数 |
|---|---|---|---|
| 系统管理员 | admin | 拥有全部功能权限，负责基础数据、用户与角色、全流程监督与运维 | 33（全部） |
| 采购经理 | manager | 负责采购审批与全流程管控、供应商维护、货运库存监督 | 31 |
| 采购员 | buyer | 负责采购订单创建/编辑/提交，跟进货运，创建销售出库单；仅见本人订单 | 17 |
| 仓储主管 | warehouse | 负责到货入库理算、库存批次管理、盘点调整与调拨、货运单证维护 | 14 |
| 财务专员 | finance | 负责落地成本分摊与关税/增值税倒算，导出采购订单，查看操作日志 | 12 |
| 生鲜品质主管 | quality | 负责冷链温控监控与温度告警处理，参与磅差理赔、临期出库与采购审批 | 9 |

关键数据规则：

- 采购订单列表对「采购员」做数据范围隔离，仅能看到本人创建的订单。
- 采购审批仅「采购经理 / 系统管理员」可操作。
- 磅差理赔、临期批次强制出库、温度告警处理由「生鲜品质主管 / 采购经理 / 系统管理员」处理。

## 三、通用功能模块详解

> 说明：下列模块按功能维度整合，各角色可使用的菜单范围见第四章。

### 3.1 经营概览

登录后的首页看板，汇总在途采购金额、库存箱数与净重、待审批事项、未处理冷链告警，并提供采购状态分布、库存温区结构、近 6 个月采购金额趋势、货运节点分布与临期批次预警。

操作要点：
- 顶部四张指标卡可快速判断资金占用、库存水位、审批积压与冷链风险。
- 「临期批次预警」列出 20 天内到期的批次，剩余天数用颜色区分（≤7 天红色、≤20 天橙色）。
- 点击右上角「刷新」重新拉取最新统计。

![经营概览](frontend/public/help/dashboard.png)

### 3.2 供应商管理

维护境外供应商档案与信用额度，采购下单时可按供应商校验可用额度。

操作要点：
- 使用顶部关键字框按名称/原产国检索，点击「查询」。
- 点击「新建供应商」填写名称、原产国、联系方式、信用额度与已占用额度。
- 列表「可用额度」= 信用额度 − 已占用额度，绿色代表充足、红色代表透支。
- 「编辑」修改档案；「删除」为软删除，若该供应商存在进行中的采购订单会被拦截。

![供应商管理](frontend/public/help/suppliers.png)

### 3.3 采购订单列表

采购订单的查询与状态流转入口，覆盖草稿、待审批、已确认、运输中、已完成等状态。

操作要点：
- 按状态与关键字筛选订单；采购员仅能看到本人创建的订单（数据范围隔离）。
- 状态流转按钮按权限显示：提交、审批通过/驳回、发货、结案、取消、删除。
- 「导出 CSV」导出当前全部采购订单（含原币金额与折合 CNY）。
- 发货后系统自动生成国际货运批次，可跳转运控控制台。

![采购订单列表](frontend/public/help/purchase-list.png)

### 3.4 新建 / 编辑采购订单

录入采购订单基础信息与明细，支持多币种锁汇、双单位联动与合同附件上传。

操作要点：
- 选择供应商后自动展示可用信用额度，超额度时给出预警提示。
- 选择非 CNY 币种可点「取实时汇率」拉取中间价，也支持手动锁汇。
- 明细行输入箱数与单箱净重自动计算总净重；切换「按箱/按 kg」计价自动换算小计。
- 必须上传电子版采购合同后才能提交审批。
- 草稿或被驳回的订单可再次编辑保存。

![新建采购订单](frontend/public/help/purchase-create.png)

### 3.5 采购订单详情

查看订单全貌：基础信息、采购明细、附件、关联货运批次、落地成本与已生成库存批次。

操作要点：
- 顶部按权限显示提交、审批、驳回、发货、结案、编辑、删除操作。
- 「采购合同附件」支持上传、下载与删除。
- 可跳转货运批次控制台、落地成本核算页。
- 底部「已生成库存批次」显示入库批次、温区与销售锁定状态。

![采购订单详情](frontend/public/help/purchase-detail.png)

### 3.6 货运批次列表

国际货运批次总览，展示船名航次、柜号、起运/目的港与单证进度。

操作要点：
- 「单证进度」显示已上传必需单证数 / 必需单证总数，未齐时显示橙色。
- 点击「控制台」进入批次详情进行节点推进与单证核销。
- 有删除权限时可删除未生成库存的批次。

![货运批次列表](frontend/public/help/shipment-list.png)

### 3.7 批次与单证控制台

以状态看板驱动货运节点流转，并通过单证核销矩阵管理提单、原产地证、植物检疫证、报关单等。

操作要点：
- 状态看板：离港 → 海运/空运中 → 到港 → 报关清关中 → 放行 → 已入库。
- 推进「运输中」前，系统校验必需单证是否齐全，缺失会阻断。
- 单证矩阵支持真实文件上传、替换与下载，并提取关键字段（提单号、柜号、封号等）。
- 「编辑货运信息」维护船名、柜号、封号、提单号、ETD/ETA 等。
- 推进到「已入库」后，关联采购订单自动结案。

![批次与单证控制台](frontend/public/help/shipment-detail.png)

### 3.8 入库理算

按实际到货数据执行重公差校验并生成可追溯库存批次。

操作要点：
- 选择已确认的采购订单与入库仓库，系统带出合同明细。
- 录入实际箱数、实际毛/净重、原产国、厂号、生产日期与保质期后点「执行理算」。
- 净重偏差 = |实际净重 − 合同净重| / 合同净重；超出公差将阻断入库并生成「磅差理赔单」二次审批。
- 校验通过后点「确认入库并生成库存批次」，批次号含国家+厂号+日期，到期日按生产日期+保质期生成。

![入库理算](frontend/public/help/wms-inbound.png)

### 3.9 库存批次

库存批次台账，默认按到期日升序（FEFO 先到期先出），支持温控记录、流水与盘点调整。

操作要点：
- 按 SKU、温区、销售状态筛选；「剩余天数」颜色标识临期风险。
- 「温控记录」查看该批次温度曲线与超限线。
- 「库存流水」查看入库、出库、盘点、报废、调拨等变动明细。
- 「盘点调整」支持库存盘点增减、报废、调拨仓库，需填写原因。
- 销售锁定批次会显示锁定原因，禁止出库。

![库存批次](frontend/public/help/wms-inventory.png)

### 3.10 落地成本核算

把海运费、关税、港杂费等附加费用按重量/货值/件数分摊到单品，得到每公斤、每箱落地成本。

操作要点：
- 选择采购订单，添加费用项并选择分摊方式（按重量/按货值/按件数）。
- 点击「计算分摊」得到货物基础成本、附加费用合计与完税后落地总成本。
- 结果表展示每个 SKU 的分摊成本、每公斤成本与每箱成本。
- 「落地成本记录」查看历史核算并支持重新核算或清除。

![落地成本核算](frontend/public/help/finance-landcost.png)

### 3.11 关税 / 增值税倒算

按 HS Code 自动带出关税税率与增值税率，计算完税价格并生成财务预付应付凭证。

操作要点：
- 选择采购订单与 HS Code（如 0810.10.00 鲜樱桃）。
- 系统按 CIF 价格计算关税、增值税与应缴合计。
- 右侧饼图展示 CIF 货值、关税、增值税构成。
- 下方「历史报关记录」可查询并删除。

![关税增值税倒算](frontend/public/help/finance-customs.png)

### 3.12 销售出库（FEFO）

销售出库按先到期先出自动分配批次；强制选择临期批次会触发品质主管二次审批。

操作要点：
- 「新建出库单」填写客户与出库明细；不指定批次时系统按到期日自动分配。
- 可手动指定批次，但被锁定批次不可选；剩余保质期 < 20% 的批次需审批。
- 展开订单可查看每个出库批次及剩余保质期比例。
- 支持编辑客户/备注；「作废」会回滚库存并生成退库流水。

![销售出库](frontend/public/help/sales-orders.png)

### 3.13 冷链温控监控

对接 IoT 温度上报，连续超温自动生成高优先级告警并锁定批次销售。

操作要点：
- 顶部可模拟传感器上报温度（选择批次 + 温度）。
- 冷藏区连续 3 次超过 4°C 触发告警并锁定批次销售。
- 「处理并解锁」由品质主管确认后解除锁定；「删除」移除告警记录。

![冷链温控监控](frontend/public/help/monitor-temperature.png)

### 3.14 审批中心

集中处理采购订单审批、磅差理赔单与临期批次强制出库等审批事项。

操作要点：
- 按状态筛选待处理 / 已通过 / 已驳回。
- 「通过」「驳回」处理审批；驳回/审批都记录处理人与时间。
- 临期批次强制出库通过后自动解除对应批次锁定。

![审批中心](frontend/public/help/approvals.png)

### 3.15 用户与角色

维护系统用户及其角色，查看角色权限矩阵。

操作要点：
- 「新建用户」设置账号、姓名、初始密码与角色。
- 「编辑」修改姓名、角色、状态，可重置密码（留空则不修改）。
- 「停用」为软删除，内置管理员不可停用或降级。
- 「角色权限说明」查看每个角色的权限项清单。

![用户与角色](frontend/public/help/users.png)

### 3.16 操作日志

记录所有写操作（新增/修改/删除）的操作人、接口路径、结果与时间，便于审计追溯。

操作要点：
- 按时间倒序展示最近的操作记录。
- 动作类型用颜色区分：POST 绿色、PUT 橙色、DELETE 红色。
- 显示请求结果（成功 / 失败及状态码）。

![操作日志](frontend/public/help/audit-logs.png)

### 3.17 我的权限

查看当前登录账号的角色与已授权功能清单。

操作要点：
- 展示账号、姓名、角色与权限数量。
- 列出当前角色全部已授权功能项。

![我的权限](frontend/public/help/profile.png)

## 四、各角色专属操作指引

### 4.1 系统管理员（admin）

**角色概述：** 拥有全部功能权限，负责系统基础数据、用户与角色、以及全流程的监督与运维。

**可用功能：** 经营概览、用户与角色、操作日志、供应商管理、采购订单列表、采购订单详情、货运批次列表、批次与单证控制台、入库理算、库存批次、落地成本核算、关税/增值税倒算、销售出库、冷链温控监控、审批中心、我的权限。

**重点操作：**
- 通过「用户与角色」创建各岗位账号并分配角色，内置管理员不可停用或降级。
- 通过「操作日志」审计全系统写操作，排查异常变更。
- 具备全部菜单与按钮，可作为全流程兜底操作人。

### 4.2 采购经理（manager）

**角色概述：** 负责采购订单的审批与全流程管控、供应商维护、货运与库存监督，并可查看经营与财务数据。

**可用功能：** 经营概览、供应商管理、采购订单列表、新建/编辑采购订单、采购订单详情、审批中心、货运批次列表、批次与单证控制台、入库理算、库存批次、落地成本核算、关税/增值税倒算、销售出库、冷链温控监控、操作日志、我的权限。

**重点操作：**
- 在「审批中心」与「采购订单」处理待审批订单（通过 / 驳回，驳回需填写原因）。
- 维护供应商档案与信用额度。
- 监督货运节点与库存水位，必要时处理冷链告警。

### 4.3 采购员（buyer）

**角色概述：** 负责采购订单的创建、编辑与提交，跟进国际货运，并可创建销售出库单。仅能查看本人创建的采购订单。

**可用功能：** 经营概览、供应商管理（查看）、采购订单列表、新建/编辑采购订单、采购订单详情、货运批次列表、批次与单证控制台、销售出库、我的权限。

**重点操作：**
- 新建采购订单：选择供应商（查看可用额度）→ 填写明细（双单位联动）→ 上传合同 → 保存。
- 草稿/被驳回订单可再次编辑后「提交审批」。
- 订单确认后可「发货」生成货运批次，进入控制台上传/维护单证。
- 在「销售出库」创建出库单，系统按 FEFO 自动分配批次。
- 注意：列表仅显示本人创建的采购订单。

### 4.4 仓储主管（warehouse）

**角色概述：** 负责到货入库理算、库存批次管理、盘点调整与调拨，以及货运节点与单证维护。

**可用功能：** 经营概览、采购订单列表、货运批次列表、批次与单证控制台、入库理算、库存批次、销售出库、冷链温控监控、我的权限。

**重点操作：**
- 在「入库理算」执行重公差校验：超公差会被阻断并生成磅差理赔单。
- 校验通过后确认入库，生成含国家+厂号+日期的追溯批次。
- 在「库存批次」执行温控记录查看、库存流水查看与盘点调整（盘点/报废/调拨）。
- 在「批次与单证控制台」推进货运节点并上传必需单证。

### 4.5 财务专员（finance）

**角色概述：** 负责落地成本分摊与关税/增值税倒算，生成财务应付凭证，并可导出采购订单、查看操作日志。

**可用功能：** 经营概览、采购订单列表、采购订单详情、落地成本核算、关税/增值税倒算、货运批次列表、库存批次、操作日志、我的权限。

**重点操作：**
- 在「落地成本核算」添加附加费用并选择分摊方式，得到每公斤/每箱落地成本。
- 在「关税/增值税倒算」选择 HS Code，计算完税价格与应缴税费，生成预付应付凭证。
- 通过「导出 CSV」导出采购订单用于财务对账。

### 4.6 生鲜品质主管（quality）

**角色概述：** 负责冷链温控监控与温度告警处理，参与磅差理赔、临期批次强制出库与采购审批。

**可用功能：** 经营概览、冷链温控监控、审批中心、采购订单列表、货运批次列表、库存批次、我的权限。

**重点操作：**
- 在「冷链温控监控」查看温度告警；冷藏区连续 3 次超过 4°C 自动告警并锁定批次。
- 「处理并解锁」确认后解除批次销售锁定。
- 在「审批中心」处理磅差理赔单与临期批次强制出库（剩余保质期 < 20%）。
